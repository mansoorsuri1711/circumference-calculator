# Circumference Calculator

Free **circumference calculator** for [circumferencecalculator.org](https://circumferencecalculator.org).

## Features

- Circumference calculator (radius, diameter, circumference, or area → full circle)
- Diameter, radius, and circle area calculator landers
- Live diagram + visible C = 2πr / C = πd formulas
- SERP-backed guides (how to find circumference, radius vs diameter, what is pi)

## Develop

```bash
npm install
npm run dev
```
